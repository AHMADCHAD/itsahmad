Shagf

Shagf

Fitness Coach Booking App

My Role: React Native Developer — Built the Complete App (Design to Deployment)

Shagf is a React Native booking platform for fitness and education services. Users purchase session packages, and the app automatically matches them with certified trainers or teachers based on their profile and goals. Features include onboarding, package purchase, session scheduling, live session tracking, progress monitoring, and account management. The education module also supports booking classes for children.

Skills & Deliverables: React Native, Redux, Websockets, Firebase, API Integration

Shagf Trainer

Shagf Trainer

Trainer & Educator Management App

My Role: React Native Developer — Built the Complete App (Design to Deployment)

Shagf Trainer is a React Native app for trainers and educators to manage sessions, schedules, and customers. Trainers update session status in real time (Scheduled, En Route, Arrived, Completed, Confirmed), allowing customers to track progress live. The app also includes availability management, leave requests, profile management, and in-app chat/call with customers.

Skills & Deliverables: React Native, API Integration, Tailwind CSS, iOS Development, Websockets

Tallah

Tallah

Service-Booking Marketplace App

My Role: Mobile App Developer

Tallah is a service-booking marketplace app I built in React Native for the beauty and grooming space. It lets users discover nearby barber shops and salons on a live map, browse each shop's services and real-time availability, add multiple services to a cart, and check out with tax calculated automatically. I also built out the account layer — a prepaid wallet with balance and loyalty points, gift card purchase/redemption, and appointment/order history — so the whole experience feels like a complete marketplace, not just a booking form.

Skills & Deliverables: React Native, OpenAI API, Firebase, Firebase Cloud Firestore, API Integration

Code Quiz

Code Quiz

AI-Powered Skill Assessment Tool

My Role: Mobile App Developer

Code Quiz is a mobile skill-assessment tool I built end-to-end in React Native. Instead of static question banks, it dynamically generates quizzes based on the skills a user selects, then scores and reviews their answers in real time. I focused on making the whole flow — skill selection, live quiz-taking, AI generation state, and results — feel fast and polished, with a consistent dark-mode design system across every screen.

Skills & Deliverables: React Native, JavaScript, OpenAI API
